# F06/F07/F08 设备资源绑定

- IDevice 创建不可变采样纹理、独立采样器、显式布局与绑定集。常量使用现有 BufferHandle 的对齐字节范围。Null 与 Vulkan 共用参数、归属和状态校验。
- 管线按 SPIR-V 模块中的资源声明验证槽位、类型和可见阶段。ICommandList 在 Pass 内绑定匹配的资源集合。录制和提交保留已有错误恢复语义。
- 布局最多 8 槽，绑定集固定为 set 0。绑定集保留资源，管线保留布局。录制引用阻止资源过早销毁和常量缓冲主机写入。
- T45 在 Null/Vulkan 验证布局、范围、跨设备错误、依赖、命令状态以及提交失败后补充屏障重试。
- T46 从迁移后的 SDK 独立构建，验证纹理采样、常量偏移与变换、索引和深度的合成像素。窗口接入继续沿用现有 Presenter。
