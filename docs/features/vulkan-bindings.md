# F08 可复用纹理绑定规格

首批实现是 Presenter 内的单槽不可变纹理绑定。纹理、采样器和绑定各有带归属的强类型句柄。纹理上传、采样器和描述符对象均封装在 Vulkan 后端，公共接口不暴露图形 SDK。

- 图像和采样器可分别复用。绑定持有两者，绘制配置持有绑定。销毁按依赖逆序执行。
- Vulkan 使用组合图像采样描述符，保留已有固定纹理入口。绑定切换不会重新上传图像。
- T40 通过同一纹理的钳位和重复采样验证实际像素，并覆盖资源忙、跨 Presenter、销毁失效、重置后复用及迁移安装。

用法与当前槽位限制见 [纹理绑定指南](../vulkan-bindings.md)。
