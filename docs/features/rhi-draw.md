# F06/F09/F10 设备绘制首批

版本为 0.1.0-draft.16。本批在已实现设备管线之上，交付设备级离屏附件、Pass、几何绑定、Draw/DrawIndexed 与同步颜色读回。

- 资源采用设备归属和代数校验，命令持有附件、缓冲与管线，录制失败保留旧状态，整批提交先校验后执行。
- Null 保存附件字节、执行清除并验证命令契约。Vulkan 创建真实图像、帧缓冲与原生命令，使用共享管线和 RenderPass 创建逻辑。
- T43 覆盖共享录制和资源生命周期、失败恢复、两种附件类型、跨列表状态预测与读回。
- T44 在 Vulkan 上读取真实像素，覆盖索引宽度、起点、顶点偏移、裁剪、深度遮挡与管线和附件复用。
- 迁移安装后的独立程序用同一公开 API 完成索引绘制与读回，并在 Vulkan 配置下要求验证层无错误。
- 支持单颜色附件、可选 D32 深度、清除并保存。可用的提交流程见 [离屏异步提交规格](rhi-async-submit.md) 和 [窗口帧规格](window-frame.md)。
