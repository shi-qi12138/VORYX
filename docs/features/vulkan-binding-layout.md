# F08 显式绑定布局与常量缓冲

- Vulkan 窗口 Presenter 同步上传不可变常量缓冲。支持在 `set 0` 的 1 至 8 个槽中绑定常量缓冲、RGBA8 采样纹理和独立采样器。Win32、X11 和原生 Wayland 共用实现。
- 布局声明每槽类型和顶点、片元可见性。绑定集按槽号严格匹配布局。任何创建失败均不发布新句柄。绘制替换在新管线成功创建后提交。
- 当前绘制引用绑定集。绑定集引用布局和所有资源。占用期间显式销毁返回 `ResourceBusy`。资源限于创建它的 Presenter。
- T41 在验证层下读取真实像素，同时检查常量数据副本、稀疏槽、错误类型、重复或缺失槽、跨 Presenter 句柄、资源忙和销毁失效。窗口验证及迁移后的 SDK 样例运行公开接口。
- 本轮交付限定于 Presenter 的带 UV 非索引绘制。通用设备与命令接口的绑定、多绑定集、动态常量更新及其他后端仍在后续阶段。
