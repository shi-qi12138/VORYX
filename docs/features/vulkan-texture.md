# F06/F08/F10 Vulkan 纹理采样规格

首批纹理路径提供单张 RGBA8 图像和固定采样器。宿主提交带 UV 的非索引顶点、字节与行距及 Shader。RHI 保持通用类型，后端创建 Vulkan 图像、视图、采样器和一个组合描述符。

- 校验宽高、行距和 span 长度，按行去掉填充。共享映射缓冲用于暂存并执行原生图像复制。
- 同步完成上传。上传后布局转为 Shader 只读，描述符只写一次。缩放不重传图像或顶点。
- T37 验收 RGBA 四象限像素、非法行距、既有彩色路径、缩放恢复与迁移安装后的独立绘制。

调用与布局见 [Vulkan 纹理指南](../vulkan-texture.md)。
