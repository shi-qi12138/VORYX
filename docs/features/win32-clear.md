# F05/F12 首批窗口呈现规格

以宿主拥有的 Win32 窗口为输入，Vulkan 后端负责创建表面、选择可呈现设备、分配交换链、清屏和呈现。Runtime 选择后端，RHI 呈现契约保持无平台 SDK 类型。Win32 调用留在 Vulkan 私有 WSI 适配器。交换链与提交逻辑位于 Vulkan 通用呈现实现。

- `CreatePresenter` 不转移窗口所有权。当前只支持 Vulkan / Win32，独立于无窗口 Buffer 设备。
- FIFO 单队列执行。获取、提交、呈现有各自的同步边界。呈现 fence 完成后回收相关对象。
- 正尺寸变化时重建，最小化/零尺寸时暂停，恢复后重新呈现。宿主始终负责事件分发。
- 共享 Vulkan 初始化保留无窗口的实例扩展和设备选择路径。Linux 构建验证公共接口和原有缓冲后端。
- T33 验收真实 Win32 窗口多帧呈现、颜色参数与线程限制、缩放、最小化、恢复和销毁。SDK 安装迁移测试用公开包独立编译并运行同一场景。

接口与样例见 [Win32 清屏指南](../win32-clear.md)。完整 F05 仍需通用帧接口、X11/Wayland、取消帧与更多错误场景。
