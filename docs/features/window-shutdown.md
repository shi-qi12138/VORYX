# Vulkan 窗口限时关闭规格

关联 F05/F09/F14/F18，目标契约版本 `0.1.0-draft.21`。

- `IPresenter::Shutdown(TimeoutNs)` 在窗口线程调用。第一次有效调用停止窗口操作和新设备工作。命令列表包装仍在时返回 ResourceBusy，保持关闭中。应用可查询、等待、重置并释放命令列表。
- GPU 提交及 Vulkan 获取和呈现使用同一等待预算。0 只查询进度，超时保留关闭中的设备和交换链，可调用同一接口重试。
- 确认完成后释放未消费窗口帧、交换链、设备资源和原生设备。已提交但未呈现的帧随交换链结束，不额外呈现。关闭后设备借用只可读取缓存的能力和信息，重复关闭成功。
- 通过原生等待确认设备丢失时，释放资源并返回 DeviceLost。析构兜底保留正常清理路径。本接口约束 fence 等待预算，具体驱动清理函数和调度没有硬实时保证。
- 确定性契约测试覆盖 ResourceBusy、Timeout、保留等待和重试。三种窗口系统验证不同尺寸下直接获取并异步呈现新帧，随后在存在已提交未呈现帧时关闭。迁移 SDK 的独立应用执行同样流程。

接口用法见 [窗口帧指南](../window-frame-api.md)，测试证据见 [环境报告](../environment.md)。
