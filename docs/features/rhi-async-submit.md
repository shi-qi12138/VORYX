# 离屏异步提交规格

关联 F09/F14，交付版本 `0.1.0-draft.19`。设备共享层管理令牌、命令状态和资源生命周期；Vulkan 后端只管理原生命令、队列提交与 fence。公开接口、调用顺序和错误见 [离屏异步提交](../rhi-async-submit.md)。

| 场景 | 验收结果 |
| --- | --- |
| 异步能力及兼容 | 通过设备能力查询，Null 拒绝异步且不消费命令列表；保持默认同步提交与同步窗口帧 |
| 状态与错误恢复 | 可控的完成源复现 Pending、非阻塞查询、有限等待超时、队列满和重试；较新的完成确认可回收同一队列的更早批次 |
| 原生执行与资源保留 | Vulkan 验证层开启，连续提交两批依赖复制，不等待第一批。提前释放源句柄和命令包装，确认第二批读回原始数据 |
| 安装消费 | 迁移安装包，仅通过 `find_package` 接入。提交索引绘制后先销毁直接依赖的句柄与命令包装，再等待并核对纹理、常量变换、深度遮挡的目标像素 |

调度标签、用例编号和结果入口见 [自动化测试](../automated-testing.md) · [验证矩阵](../validation.md) · [环境报告](../environment.md)。
