# F07/F10 Vulkan 彩色三角形规格

Presenter 负责一组非索引三角形顶点和固定布局管线。`SetTriangleList` 验证输入并建立完整替换，`DrawAndPresent` 通过同一窗口提交路径绘制。实现复用 Vulkan 缓冲映射与非一致内存处理。交换链拥有逐图像视图和帧缓冲，窗口缩放仅重建这些对象并更新动态视口。

- 每次创建或替换时上传顶点并创建管线。正常帧不重新上传或编译。
- 暂停、缩放和关闭沿用同步提交及呈现 fence。外部持有窗口。
- T36 从公共 API 配置三角形，测试未配置绘制、无效替换、缩放恢复和迁移安装后独立运行。离屏 GPU 用例验证中心与角落实际像素。

实际用法和固定 Shader 布局见 [三角形接入指南](../vulkan-triangle.md)。
