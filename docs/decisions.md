# 设计决策与待定事项

状态：草案；决定可在实现验证后修订，原因与影响必须记录。

| ID | 当前决定 | 原因 / 代价 |
| --- | --- | --- |
| D01 | C++20 + CMake，对外优先 C++ API | 统一开发模型；需要明确支持的编译器和运行库配置 |
| D02 | 首版面向 Windows/Linux，DX12 只纳入 Windows | 两平台复用 Vulkan/OpenGL，实现从 M1 起验证可移植性 |
| D03 | 显式 RHI，先 Vulkan，再 DX12 与 OpenGL | 提前验证命令、资源与同步；OpenGL 需要命令流适配 |
| D04 | Runtime 负责组装，RHI 不发现后端 | 避免依赖环与隐藏创建；用户可查询实际后端 |
| D05 | 首期静态模块、显式注册 | 简化链接与生命周期；动态插件需未来独立 ABI 设计 |
| D06 | 资源句柄，设备/命令列表少量多态 | 统一验证和回收；需要句柄表及代数检查 |
| D07 | 资源销毁区分逻辑失效和 GPU 回收 | 避免在途使用悬空；需要提交记录和依赖跟踪 |
| D08 | 单渲染线程、单图形队列起步 | 缩小同步验证范围；并行录制后续独立扩展 |
| D09 | 首版先交付 Runtime + RHI | 先证明底层完整性；高层 Renderer API 暂不公开 |
| D10 | HLSL 离线生成多后端产物 | 减少手写多套 Shader；必须验证布局与语义差异 |
| D11 | 明确销毁、取消帧和 Shutdown | 正常流程与失败清理都有出口；需要后端实现额外收尾 |
| D12 | Auto：Windows 为 Vulkan → DX12 → OpenGL，Linux 为 Vulkan → OpenGL | 策略集中且可解释；Null 永远不加入自动回退 |
| D13 | 现有根 .clang-format 唯一控制格式，.clang-tidy 检查完整括号 | 保持用户样式；格式工具本身不能代替缺括号检测 |
| D14 | CTest 调度 GoogleTest，CPU/Null/GPU 分层 | 无 GPU 环境仍可验证契约；真实后端需要独立硬件证据 |

待定事项不是留给调用方猜测的参数。未解决的前置条目会阻止相关功能进入冻结或发布状态，不能在发布文档中继续使用“按环境调整”。

当前进展见 [环境报告](environment.md)：已验证 Core、Null 缓冲、Windows 硬件 Vulkan 缓冲、WSL 软件 Vulkan 及安装 SDK 接入。Q01 最低支持范围、Q04 后端依赖、Q07 统一工具版本和 Q08 远程 CI/原生 GPU 仍待冻结。Vulkan 缓冲基线确定为 Vulkan 1.2；窗口、其他后端及发布驱动范围仍待冻结。无窗口工厂与 Buffer 同步读回已在 draft.4 明确定义，不再视为未设计入口。

## 已明确不做的首版承诺

跨编译器 C++ ABI、macOS/移动平台、ARM64、DX11、Linux DX12、共享宿主 OpenGL 状态、多窗口、后端热切换和高级 GPU 特性都不属于 v0.1。若需求变化，先修改功能范围与接口契约。Linux 已在 draft.2 纳入首版，不能继续按仅 Windows 的旧假设实现。
