# 验证计划与发布验收

状态：默认 55 项包括 21 Core、24 Null 契约、4 集成和 6 环境/质量检查；七个公共头分别编译。证据见 [环境报告](environment.md)。新增 Vulkan 缓冲共享契约、直接与安装样例执行；WSI 和远程 CI 尚未交付，不对图形绘制或性能作通过声明。

## 1. 测试分层

| 层次 | 验证内容 | 不能证明 |
| --- | --- | --- |
| 文档检查 | 本地链接、状态标签、术语、示例与契约一致 | C++ 编译和 GPU 行为 |
| Core 单元与接入 | 错误持有、结果分支、终止契约、日志、头自包含和独立应用接入 | RHI、同步和实际 GPU 行为 |
| 契约测试 / Null | 句柄、CPU 依赖、错误、命令与帧状态机 | 真实图像和驱动同步 |
| 编译与集成 | 公共头自包含、targets、开关、独立消费 | 所有硬件和驱动兼容 |
| 真实后端 | 清屏、绘制、屏障、交换链与设备诊断 | 其他未测设备或版本 |
| 跨后端图像 | 空间、颜色、布局与相同输入结果 | 像素逐位一致或性能等价 |

## 3. 图像与同步验收

共同样例覆盖清屏、三角形、索引网格、非对称纹理、常量布局、深度、剔除与颜色空间；使用相同数据和渲染语义。容差在 Q05 中实测确定，不能用扩大容差掩盖方向、绑定或颜色错误。

Vulkan 使用可用的验证层和同步验证；DX12 使用可用的调试层并视测试需要启用 GPU 验证；OpenGL 使用可用的调试输出与错误检查。具体组件版本在环境支持表中固定。验证组件缺失要记录，不能记为“无错误”。

特别验证图形执行完成与呈现完成的区别、获取图像取消、交换链重建、延迟回收和失效路径；一次三角形截图不足以通过后端验收。

## 4. 证据格式

每次后端验收记录：功能/用例 ID、代码版本、文档契约版本、日期、操作系统、编译器/运行库、SDK、GPU、驱动、构建选项、验证组件状态、操作与预期、实际结果、日志/图像位置、已知限制。

结果只能写“通过 / 失败 / 未执行 / 不适用”，不适用须说明原因。没有证据的功能不得标记“已验证”。性能结论另行提供场景、分辨率、采样方式、CPU/GPU 计时与统计，不从功能测试推断。

## 5. 发布门槛

- [功能规格](requirements.md) 中 v0.1 功能均有对应实现和证据。
- 所有声明支持的真实后端运行共同用例，失败项有修复或明确缩减范围。
- 无未解释的验证错误；警告需要逐项说明或修复。
- 支持矩阵、构建安装、Shader 工具和独立用户样例可复现。
- 接口、示例、默认值、错误恢复和实现一致，已处理发布范围内全部待定事项。
- 草案教程替换为实际可构建示例，同时保留失败和退出流程。
- 发布记录明确尚未支持的功能；不将设计目标展示为当前能力。
- 根格式配置与完整括号检查通过；自动化套件及预期用例确实执行，必需套件不能空跑或全部跳过。

当前可执行子集：Null 缓冲，以及 Windows 硬件/WSL 软件 Vulkan 缓冲；具体配置证据见环境报告。Win32 Vulkan 清屏与呈现已验收。X11 清屏已完成 WSLg 软件验收。Wayland 清屏已完成 WSLg 软件验收。固定布局 Vulkan 三角形已实现。OpenGL、DX12 与通用图形管线仍待实现。

系统/窗口/后端目标矩阵见 [跨平台设计](cross-platform.md)。Windows 和 Ubuntu WSL2 的 CPU/Null、SDK 与原生 GPU 验收分别记录；原生 Linux GPU/WSI 未执行，不能以 WSL CPU 结果标记图形支持。
